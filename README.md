
# Online Bookstore E-Commerce

A web-based e-commerce application developed using ASP.NET Core MVC, C#, Entity Framework Core, SQL Server, and ASP.NET Core Identity.

The project focuses on building a database-driven online bookstore with user authentication, role-based access control, and shopping features.

## Technologies

- C# and ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- HTML, CSS, Bootstrap
- Git and GitHub

## Features

- User registration and login
- Role-based authorization (Admin and User)
- Book, author, category, and publisher management
- Book catalog with cover images and search functionality
- Book descriptions and ISBN information
- User reviews and ratings
- User-specific favorites
- Shopping cart functionality
- Order placement without online payment integration
- Responsive web interface

## How to Run the Application

This project is an ASP.NET Core MVC application that runs locally.

### Requirements
- Visual Studio with ASP.NET Core development support
- .NET SDK compatible with the project
- SQL Server LocalDB

### Setup Instructions

1. Clone or download this GitHub repository.
2. Open `LibrarieOnline_ECommerce.slnx` in Visual Studio.
3. Restore the required NuGet packages.
4. Configure the SQL Server connection string in `appsettings.json`.
5. Configure the required local administrator settings.
6. Set up the database using Entity Framework Core migrations.
7. Run the application using the HTTPS launch profile.
8. Open the local HTTPS address displayed by Visual Studio.

### User Access

- New visitors can register for a User account.
- Registered users can browse books, manage favorites, write reviews, use the shopping cart, and place orders.
- Administrator access is restricted to authorized accounts.

**Note:** The application is not currently hosted online. It must be configured and run locally to access its features. Screenshots are provided above for visitors who want to explore the interface without installing the project.
